TAABEER is a bespoke editorial WordPress theme for a London-based curated house of Pakistani design.

== Setup ==

1. Install and activate this theme.
2. Install the free Elementor plugin. Install WooCommerce when product management is required.
3. Open Appearance > Taabeer Setup.
4. Select Import Taabeer Demo.
5. Replace the temporary wordmark and every concept image with approved brand assets.
6. Review and approve pages marked as drafts before publication.

== Editing ==

The imported pages, header and footer are editable with the free Elementor plugin. Theme options for approved business details are available under Appearance > Customize. Commerce launch and consent-aware Google Analytics settings are under Appearance > Taabeer Setup.

== Commerce safety ==

Prices and purchasing stay disabled after import. Enable them only after products, payments, tax, shipping, stock, legal wording and checkout have been tested.

== Concept photography ==

Images under assets/images/demo are placeholders for layout review. Replace them with licensed, client-approved photography before public launch. Never infer an artisan, maker, place, community or product attribution from these images.
