# Taabeer WordPress Theme

Taabeer is a custom editorial WordPress theme prepared for free Elementor and WooCommerce. It includes an Appearance > Taabeer Setup screen that creates the page structure, navigation, collections, Discover Pakistan pages, draft editorial content and WooCommerce sample data.

## Local preview

1. Copy `.env.example` to `.env` and use local-only passwords.
2. Run `docker compose up -d`.
3. Open `http://localhost:8080`, complete WordPress setup and activate **Taabeer**.
4. Install the free Elementor and WooCommerce plugins if required.
5. Open Appearance > Taabeer Setup and run the importer once.

## Publication notes

The working tagline, proposed colours, business details, legal policies, newsletter flow, analytics ID, delivery rules and sale-ready product information remain subject to client approval.

## GitHub deployment

Install the packaged **TAABEER Deployment Manager** plugin, connect this repository under Tools > TAABEER Updates, and deploy verified releases without uploading the theme ZIP again. See [GIT-DEPLOYMENT.md](GIT-DEPLOYMENT.md).
